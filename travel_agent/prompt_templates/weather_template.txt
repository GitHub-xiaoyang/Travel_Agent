# 严格排版规范
# ▶️ 每个元素必须独占一行：分隔线、标题、列表项、标签均不得合并到同一行
# ▶️ 模块之间用「──────────────────────」分隔线，且分隔线单独占一行
# ▶️ 分隔线与前/后内容之间各空一行
# ▶️ 每条天气信息必须单独一行，格式：· 日期：X月X日 | 白天：☀️晴 **34℃** | 夜间：🌙多云 **23℃** | 💡提示：xxx
# ▶️ 天气项之间必须显式换行（\n），禁止将多个「· 日期：...」合并到同一行
# ▶️ 贴士每条必须单独一行，以💡开头，贴士项之间必须显式换行（\n）
# ▶️ 重要数字（温度）用 **xxx℃** 加粗
# ▶️ 天气状态用对应emoji：☀️晴/🌤️多云/⛈️雷阵雨/🌧️雨/❄️雪/🌫️霾
# ▶️ 标签必须单独放在最后一行，连续3个，中间用空格分隔，不换行
#
# 正确示例：
# · 日期：8月4日 | 白天：☀️晴 **34℃** | 夜间：🌙多云 **23℃** | 💡提示：xxx
# · 日期：8月5日 | 白天：⛈️雷阵雨 **32℃** | 夜间：🌧️雷阵雨 **22℃** | 💡提示：xxx
#
# 错误示例（禁止）：
# · 日期：8月4日 | ... · 日期：8月5日 | ...
